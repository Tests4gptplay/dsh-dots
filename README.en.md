# DSH Dots

Use [ChatGPT Dots](https://chatgpt.com/dots/home) directly inside DeepSeek Harness. Desktop preloads Dots at startup, keeps the webpage and its state when switching DSH panels, and offers Reload and Open in browser controls.

The toolbar and ring icon adapt to DSH's light and dark themes, with Chinese and English interface text. Sign in to ChatGPT on the official website.

**Login retention (Desktop):** Open **DSH Settings → Dots Login Retention** to check status, apply, or restore the Dots-specific persistent browser setup.

## Install DSH Dots 1.0.12 (classic edition)

In DeepSeek Harness, open **Plugins → Add plugin** and enter this pinned branch in the package name or address field:

```text
github:Tests4gptplay/dsh-dots#1.0.12
```

Alternatively, install the fixed 1.0.12 release tag:

```text
github:Tests4gptplay/dsh-dots#v1.0.12
```

[Download the 1.0.12 release package](https://github.com/Tests4gptplay/dsh-dots/releases/download/v1.0.12/dsh-dots-1.0.12.tgz) · [Version 1.0.12 release and installation notes](docs/releases/v1.0.12.md)

**Published npm package**: `@tests4gptplay/dsh-dots@1.0.12`.

Open **DSH Dots** in the sidebar and sign in on the official ChatGPT page. Manage Desktop login retention in DSH Settings.
