# DSH Dots 2.0.1-test.10：Tunnel 单次启动时序修复

[返回候选版 README](../../README.md) · [原正式版 v2.0.0](https://github.com/Tests4gptplay/dsh-dots/releases/tag/v2.0.0)

## 变更

在当前 DSH 进程恢复已经启用的 Tunnel 时，MCP 本地 HTTP 监听确认成功后，改为只安排一次延后 1.5 秒的启动。插件卸载时取消尚未执行的启动。启动执行后计时器立即释放，不保留后台轮询、心跳或重试循环。

当用户在排队期间手动停止时，原有持久化配置会记录停止，随后执行的 `initialize()` 不会重新启动 Tunnel。已有 Runtime API Key、Tunnel ID、MCP 设置、WebView、主动通知和全部配置指南沿用 v2.0.0。
