# DSH Dots v0.1.0 — 正式发行

## 修复与改进

- 根据 DSH 用户实机截图反馈，移除“大标题 + 说明 + 浏览器外框”的布局，改为直接承载 Dot 网页的 DSH 原生全幅内容区。
- **DSH Desktop**：通过宿主 `dshDesktop.browser.acquire()` 获得经主进程批准的 Electron WebView Guest，加载官方 `https://chatgpt.com/dots/home`；不再调用在独立主页面不可用的 Session 侧栏 Browser。
- 顶栏、背景、圆环、按钮基于 DSH 主题变量；网页内部样式仍由 ChatGPT 网站控制。
- 保留「刷新」「在浏览器打开」，并修复 `noopener` 打开动作的错误返回值判断。
- 新增 WebView 宿主租约、异步释放、防止误导航以及无侧栏 Browser 时的自动化回归。
- `@deepseek-ai/*` 依赖继续由宿主提供，不硬锁 DSH 版本号。

## 安装

DSH Desktop：「插件 → 添加插件」：

```text
github:Tests4gptplay/dsh-dots#v0.1.0
```

Web profile：

```bash
dsh plugin --profile web add 'github:Tests4gptplay/dsh-dots#v0.1.0'
```

备用包：`dsh-dots-0.1.0.tgz`，由同一次 GitHub Release 提供。由旧版升级时只替换 Dots 插件并重启 DSH，不删除 Profile、其他插件或用户资料。

## 实测边界

已通过源码、模拟后台、Chromium 以及 GitHub Windows/Ubuntu 构建和打包验证（以最终 CI 结果为准）。**真实 ChatGPT Dot 登录、网页内部配色与 Cookie 在重启后是否延续，必须在目标 DSH 客户端实测，不能由模拟环境代替。** Desktop 使用独立的主进程批准 WebView，不做非官方 API 调用，不绕过宿主安全策略。
