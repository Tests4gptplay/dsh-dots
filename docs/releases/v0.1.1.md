# DSH Dots v0.1.1 — 正式修复版

## 修复

- 根据 DSH Desktop 真实截图修复 ChatGPT 登录界面只显示顶部约一小条的布局错误：恢复 Electron `<webview>` 的 `display:flex`，保留内部 Shadow iframe 的全高布局，并将 Dots 面板设置为 DSH 容器中的可伸缩子元素。
- 复用 DSH 官方网页 Guest bridge 的原有隔离/导航策略，保持页面为 DSH 原生全幅布局；不改 ChatGPT 网页 DOM、不导出 Cookie、不绕过登录限制。
- 新增 Chromium 真实 CSS 回归：模拟 Electron Shadow iframe 并验证全屏高度、窗口缩小时跟随调整；同时通过真实 DSH rc.3 源码接口测试、模拟 Dot 测试以及发行包校验。

- 2026-10-26 原位修复安装：移除误写入 `package.json` 的 `dsh-dots: file:dsh-dots-0.1.1.tgz` 自依赖，解决 pnpm 安装时查找本地 TGZ 报 ENOENT 的问题；增加发行包的 pnpm 安装测试。版本号、Tag 名称和安装入口均保持 v0.1.1。此修复更新了同版本 Release 的 TGZ 文件，其 SHA-256 与首次发行时不同。

## 安装

DSH Desktop：插件 → 添加插件：

```text
github:Tests4gptplay/dsh-dots#v0.1.1
```

DSH Web：

```bash
dsh plugin --profile web add 'github:Tests4gptplay/dsh-dots#v0.1.1'
```

备用发行包：`dsh-dots-0.1.1.tgz`。安装并启用后重启 DSH；升级时只替换 Dots 插件，不删除其它插件、配置或用户登录数据。

## 验收范围

已通过模拟宿主、浏览器渲染和 DSH 源码 API 检查；**真实 ChatGPT 登录是否接受 DSH Electron 容器，和登录是否能保持跨重启，仍需要目标机器实测。** Electron/DSH 浏览器策略不允许通过插件擅自修改。
