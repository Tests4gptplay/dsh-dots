# DSH Dot MCP 1.0.4

- **新增排障技能库。** 在「设置 → Dot MCP → 排障技能」查看、搜索和维护经验。Dot 可通过 MCP 查阅技能，并在验证解法后补记。新装默认留空，升级保留已有条目。
- **改进任务执行指引。** Dot 能直接完成的操作不交给 DSH 里的 AI 代办；需要会话时优先复用，按指定的工作区归组并命名。遇到问题先尝试解决，再报告结果。
- **沿用原有安装身份和设置。** 本次不添加权限绑定或更改默认会话权限。

在 DSH 插件管理中安装或更新 `dsh-dot-mcp@1.0.4`，也可使用本页的 `dsh-dot-mcp-1.0.4.tgz`。

## English

- Added a searchable troubleshooting library in **Settings → Dot MCP → Skills**. Dot can read it and save verified fixes through MCP. New libraries start empty; existing notes are preserved.
- Clarified when Dot should act directly, reuse a DSH session, or delegate a task to DSH AI.
- This release keeps the existing package identity and settings. It does not add permission binding or change default session permissions.
