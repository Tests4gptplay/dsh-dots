# DSH Dots v1.0.9

## 更新内容

- **启动预加载**：DSH Desktop 加载插件后即在后台打开 Dots。
- **切换保留**：切到聊天或其他页面时只隐藏网页，返回时直接显示同一个页面，不重新加载，也不丢失页面状态。
- **原生布局**：常驻页面位于 DSH 原生的中间内容列，不使用窗口外层悬浮载体。
- **皮肤兼容**：页面使用独立堆叠上下文，修复部分皮肤给插件面板叠加半透明毛玻璃层、导致页面发淡发糊的问题。
- **兜底**：常驻页面无法显示时自动退回页面内渲染，不留下空白面板。
- **登录态**：提供 Desktop 持久分区配套更新脚本，把 Dots 存储固定到 `persist:dsh-dots-personal-browser`，包含备份与完整性校验；其他网页的浏览器分区策略保持不变。
- 刷新按钮仍主动重载；禁用插件或退出 DSH 时释放网页。

## 安装

DSH「插件 → 添加插件」：

```text
github:Tests4gptplay/dsh-dots#v1.0.9
```

安装并启用后重启 DSH。附件提供预打包 `.tgz`。

需要跨重启保留登录态时，按 [Desktop 登录态持久化说明](https://github.com/Tests4gptplay/dsh-dots/blob/v1.0.9/README.md#desktop-登录态持久化) 应用配套更新；已经应用过的用户直接升级插件即可。

## English

Version 1.0.9 preloads Dots at Desktop startup and keeps the same WebView alive across panel switches. The page now lives in DSH's native center column with its own stacking context, so translucent skin layers no longer wash it out, and it falls back to in-panel rendering if the persistent page cannot be shown. A companion Windows Desktop helper keeps Dots storage in a fixed persistent partition. Install the pinned source above and restart DSH. See the [English guide](https://github.com/Tests4gptplay/dsh-dots/blob/v1.0.9/README.en.md).
