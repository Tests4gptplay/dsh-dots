# DSH Dots 2.0.1-test.3：官方 Tunnel Client 更新与版本清理

[返回项目说明](../../README.md) · [上版隧道接入说明](v2.0.1-test.2.md)

## 变更

- 「下载并安装官方客户端」每次执行都重新查询 OpenAI `openai/tunnel-client` GitHub Releases 的 **latest**，选择适合当前系统及架构的官方归档，并按 GitHub 官方 SHA-256 校验。
- Dots 安装包仅包含安装与管理逻辑；官方可执行文件由用户点击后下载到 DSH profile 下的指定目录。
- 安装成功后保留**当前版本 + 上一份已安装版本**；自动清理同目录下更早的、匹配 Dots 安装命名的官方客户端目录。
- 若旧客户端仍在运行，则保留到进程停止后再完成清理，避免 Windows 正在使用的文件被删除。
- 用户自选的外部可执行文件，以及无关目录和文件不纳入清理。下载、校验或配置写入失败时保留现有客户端。
- MCP 协议、工具调用、登录保持与其他插件维持原有行为。

## DSH 原生安装

在「插件 → 添加插件 → 包名或地址」输入：

```text
github:Tests4gptplay/dsh-dots#2.0.1-test.3
```

进入「设置 → Dots → OpenAI Secure MCP Tunnel」，点击「下载并安装官方客户端」。Tunnel ID、Runtime API Key、启动和连接检查继续使用已有操作方式。

## 测试入口

- `tests/tunnel.test.mjs`：清理只保留当前版与一份旧版、在用程序临时保留、无关目录不受影响。
- `tests/tunnel-official.test.mjs`：使用官方可执行文件，连续三次安装均重新查询最新 Release，停止进程后验证旧安装目录已清理。
- `npm test` 与 `npm run pack:check`：源码回归、生成运行包与白名单核对。

完整构建结果以对应分支 GitHub Actions 记录为准。
