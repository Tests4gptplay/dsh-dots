### 保持原样的功能与合理校验

Dots 内嵌官方网页、预加载、切换页面保留、主题适配和刷新不变。申请浏览器 WebView 依旧使用 DSH 原有租约。登录操作由 ChatGPT 官方网页执行，插件无需读取或保存 Cookie、Token。ASAR 修改前仍需识别真实目标模块、备份原文件并校验文件 SHA 和恢复来源；这项校验对应修改宿主安装文件的真实完整性要求，并非按 DSH 版本字符串拒绝安装。

一次性退出后处理仍使用已有 DSH Host 的 IPC 断开事件，不新增心跳、Watchdog、轮询或额外的执行时限。MCP 尚未开发。

## 验证与证据

- **修改前复现：** 六个行为回归断言失败，记录在审查工作区 `before-fix-tests.log`。失败类型分别为 WebView 短暂零高度、设置区块过早跳过、排队恢复误报、编译代码空格差异、暂存 JSON 损坏、失败辅助任务退出码为零。
- **修改后回归：** 完整 `npm test` 49 项通过、0 失败、0 跳过（Linux Node 22.16.0）。新增归档回滚、历史暂存清理、编译代码格式差异和过长源码等回归断言。
- **包内文件：** `npm run pack:check` 验证 13 个生产文件，旧 Python 脚本、测试假网页、模拟后端没有打包。
- **跨系统 CI：** 由本测试分支的 GitHub Actions 记录确认 Windows 和 Ubuntu 的测试、npm/pnpm 安装与生产包检查。历史运行结果以对应提交为准。
- **真实 DSH Desktop 登录验收：** 仍需在用户实际安装中检查设置按钮 → 完全退出（含托盘）→ 启动 → Dots 登录状态保留与原版恢复。

平台差异：Windows 安装文件占用时执行退出后单次修改；macOS 签名应用的安装资源需要遵循签名机制；Linux 安装形式如只读 AppImage 需满足写入路径要求。此说明放在 GitHub 开发／发行资料，插件设置页只呈现功能操作和真实状态。
