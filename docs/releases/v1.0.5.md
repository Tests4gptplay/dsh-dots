# DSH Dots v1.0.5

## 更新内容

- **启动即预加载**：DSH Desktop 加载插件时在后台打开 Dots。
- **切换页面保留状态**：使用同一个 WebView，返回 Dots 时直接显示已有网页；刷新按钮仍主动刷新。
- **复用登录存储**：沿用宿主分区，并提供 Windows DSH 0.2.1-rc.3 的 Dots 持久分区配套更新脚本。
- 保留全幅页面、随 DSH 主题适配的工具栏和中英文界面。

## 安装

DSH「插件 → 添加插件」：

```text
github:Tests4gptplay/dsh-dots#v1.0.5
```

安装并启用后重启 DSH。附件提供预打包 `.tgz`。需要配置跨重启登录存储时，按照 [Desktop 登录态持久化说明](https://github.com/Tests4gptplay/dsh-dots/blob/v1.0.5/README.md#desktop-登录态持久化) 应用配套更新；已应用的用户直接升级插件即可。

## English

Version 1.0.5 preloads Dots at Desktop startup and retains the same WebView across page switches. Reload remains an explicit action. Existing host-managed login storage is reused, and a Windows DSH 0.2.1-rc.3 companion persistence helper is included. Install the pinned source above and restart DSH. See the [English guide](https://github.com/Tests4gptplay/dsh-dots/blob/v1.0.5/README.en.md).
