# DSH Dots 2.0.1-test.5：MCP 关闭与客户端版本切换修复

[项目介绍](../../README.md) · [2.0.1-test.4 请求内事件流](v2.0.1-test.4.md)

## 修复内容

### MCP 关闭后设置持久化

用户关闭 MCP 时，先尝试关闭本地 MCP 监听和官方隧道进程；如果隧道进程停止时报错，MCP 的关闭偏好仍独立写入当前 profile。界面显示实际清理错误，下一次 DSH 启动按保存的关闭状态执行。

关闭偏好写盘本身失败时，保留原先的具体错误反馈机制。此次改动不改变已交给 DSH 的任务状态。

### 已下载新客户端的显式切换

点击「下载并安装官方客户端」继续从 OpenAI GitHub Releases 读取最新版本并校验安装。若原隧道客户端还在运行，设置页提示「新客户端已下载，当前仍在运行旧客户端」。

用户点击「启动隧道」后，如选中路径与当前运行路径不同，就先停止旧客户端，再调用官方客户端的 `init` 和 `run` 启动所选版本。若路径相同，维持原有运行进程。原有最多保留一份历史备份的目录清理行为继续生效。
