## 修正

依据 Windows DSH 重启后反馈，将此前的定时延后 Tunnel 自动启动改为：MCP 本地监听就绪后，读取用户保存的安装目录、可执行文件和 Tunnel ID，并执行与设置页按钮一致的 `start(配置)`。

- 一次启动任务，共用正在执行的 Promise，不新建第二条启动路径
- MCP 正常启动与响应独立于 Tunnel 子进程的启动耗时
- Tunnel 状态查询与正在执行的单次启动同步，返回完成后的实际状态或错误
- 用户此前主动停止时保持关闭；MCP 关闭或插件卸载仍使用原生资源清理
- 不增加后台轮询、额外计时器、循环重试和守护进程

保留正式 2.0.1 的其他设置、UI、MCP、通知、登录保持及工具接口。
