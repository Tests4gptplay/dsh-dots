# DSH Dots v1.0.12

## 更新内容

- **登录保持设置**：在 DSH「设置 → Dots 登录保持」查看状态、一键应用及恢复 Dots 专属的浏览器持久化修复。
- **可恢复的本地修复**：修复 DSH Desktop 的 Dots 浏览器分区分配，原有其他浏览器分区保持不变；应用前保存原版归档并校验。更新 DSH 后可以重新检查和应用。
- **交互体验**：保留官方 Dots 网页、启动预加载、面板切换状态保留、主题工具栏、刷新和外部浏览器入口。修正页面临时零高度、设置项加载时序及修复状态处理问题。
- **升级兼容**：GitHub 安装包沿用 `dsh-dots` 标识，可升级既有正式版本；npm 独立发行包使用 `@tests4gptplay/dsh-dots`。

## 安装

在 DSH「插件 → 添加插件」的「包名或地址」输入：

```text
github:Tests4gptplay/dsh-dots#v1.0.12
```

简洁版长期维护分支的安装地址为：

```text
github:Tests4gptplay/dsh-dots#1.0.12
```

或者使用本 Release 的预构建安装包：

https://github.com/Tests4gptplay/dsh-dots/releases/download/v1.0.12/dsh-dots-1.0.12.tgz

**npm 安装**：`dsh-dots@1.0.12`（首次发布完成后可使用），与 MCP 版的 `dsh-dot-mcp@1.0.0` 使用不同的插件安装身份。

在设置页应用登录保持修复后，完全退出并重新启动 DSH Desktop；登录仍在 ChatGPT 官方网页完成。
