# DSH Dots 2.0.1：Tunnel 自动启动时序修复

[返回项目说明](../../README.md) · [上一正式版 2.0.0](v2.0.0.md) · [完整连接指南](../../README.md#连接自己的-dot)

## 本版改进

当 DSH 重新启动且用户已启用 OpenAI Secure MCP Tunnel 时，MCP 本地 HTTP 服务监听成功后，安排 **一次性延后 1.5 秒**启动 Tunnel Client。启动完成后计时器立即退出，无常驻轮询或自动重试循环。

关闭 MCP 会取消尚未执行的 Tunnel 启动，重新开启 MCP 后允许再安排一次；插件卸载同样取消未执行的启动。手动停止 Tunnel 仍会保存为停止状态，下次启动不会自行开启。

沿用正式版 2.0.0 的其余能力：Dots 网页导航、点击图标返回首页、设置页统一视觉、完整折叠配置指南、登录保持、17 个 MCP 工具入口、Session 级主动通知及现有 Tunnel ID、客户端路径与 Runtime API Key 保存方式。

## 安装

在 DSH「插件 → 添加插件」中填写：

```text
github:Tests4gptplay/dsh-dots#v2.0.1
```
