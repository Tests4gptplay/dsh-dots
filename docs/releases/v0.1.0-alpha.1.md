# DSH Dots v0.1.0-alpha.1（候选）

首个 DSH 原生 Dots 网页入口候选版本：圆环状态栏、中文默认/英文辅助、内置 DSH Browser 和系统浏览器入口，以及隔离模拟对话自动化测试。

## 安装

GitHub 版本 Tag **发布成功后**，在 DSH Desktop「插件 → 添加插件」输入：

```text
github:Tests4gptplay/dsh-dots#v0.1.0-alpha.1
```

Web 版：

```bash
dsh plugin --profile web add 'github:Tests4gptplay/dsh-dots#v0.1.0-alpha.1'
```

备用文件：`dsh-dots-0.1.0-alpha.1.tgz`，应与本 Release 关联。启用后重启 DSH 一次。Web 和 Desktop 分别安装，升级时不要删除其他插件或 DSH 用户 Profile。

**验收限制**：Chromium／DSH 接口模拟测试不能证明 ChatGPT 的真实 iframe、WebView 登录和 Cookie 持久性；首次发行之前仍需在实际 DSH Desktop 登录测试。
