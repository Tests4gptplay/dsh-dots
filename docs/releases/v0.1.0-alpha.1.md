# DSH Dots v0.1.0-alpha.1（预发布）

首个 DSH 原生 Dots 网页入口候选版本：圆环状态栏、中文默认/英文辅助、内置 DSH Browser 和系统浏览器入口，以及隔离模拟对话自动化测试。

## 安装

GitHub 版本 Tag 与 Release 实际发布后，在 DSH Desktop「插件 → 添加插件」输入：

```text
github:Tests4gptplay/dsh-dots#v0.1.0-alpha.1
```

Web 版：

```bash
dsh plugin --profile web add 'github:Tests4gptplay/dsh-dots#v0.1.0-alpha.1'
```

备用文件：`dsh-dots-0.1.0-alpha.1.tgz`，应与本 Release 关联。启用后重启 DSH 一次。Web 和 Desktop 分别安装，升级时不要删除其他插件或 DSH 用户 Profile。

**预发布验收边界**：Windows/Ubuntu 包安装与 Mock Dot/DSH 接口测试不等于真实 Dots 登录。ChatGPT 网站 iframe、DSH Desktop WebView 登录以及 Cookie 在重启后的保持情况尚待用户本机实测；不能声称已实机验证或已经获得非官方 Dots API。该版本是供实机验证的公开 alpha 测试包。

## 发行核对

由 GitHub Actions 在提交更新后的版本说明时构建，运行 DSH 原生 Slot 接口、Mock Dot 对话及包内容验证，并发布与 Tag 绑定的预编译 TGZ；不用用户在安装时进行本机构建。
