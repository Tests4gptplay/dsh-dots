# DSH Dots 2.0.2：Tunnel 自动恢复与配置沿用

[项目说明](../../README.md) · [English](v2.0.2.en.md) · [配置指南](../../README.md#连接自己的-dot)

## 本版更新

DSH Dots 2.0.2 基于用户在 Windows DSH 上验收生效的 `2.0.2-test.1`。MCP 本地监听就绪后，Tunnel 自动恢复会读取当前 DSH 配置中保存的客户端安装目录、可执行文件路径和 Tunnel ID，直接使用与设置页「启动隧道」按钮一致的 `start(配置)` 执行路径。

自动启动只执行一次，正在启动或已经运行的客户端不会重复启动；MCP 可以正常启动和响应，设置页会取得此次启动完成后的实际状态。手动停止的选择继续保存。沿用原有 Tunnel Runtime API Key 持久化、登录保持和完整 MCP 功能。

本版采用已确认的设置页视觉布局、可折叠五步指南、网页后退、点击 Dots 图标返回首页、17 个 MCP 工具入口与按 Session 的主动通知设置。

## 配置与升级

在 DSH「插件 → 添加插件」中输入：

```text
github:Tests4gptplay/dsh-dots#v2.0.2
```

已有 Tunnel ID 和客户端安装目录会随当前 DSH 用户配置保留。若遇到 `CONTROL_PLANE_API_KEY is empty`，在 Dots 设置中重新输入已有的 Runtime API Key 并启动隧道；无需重新创建 Tunnel ID。本次实机反馈确认重新输入 Key 后，客户端恢复连接并在重启后正常运行。
