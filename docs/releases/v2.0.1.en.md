# DSH Dots 2.0.1: One-shot Tunnel startup

[Project README](../../README.en.md) · [2.0.0 release notes](v2.0.0.en.md) · [Connection guide](../../README.en.md#connect-your-dot)

## Update

After DSH restarts with an enabled OpenAI Secure MCP Tunnel, Dots schedules **one Tunnel Client start 1.5 seconds after the local MCP HTTP listener is ready**. Once fired, the timer is released; no periodic polling or automatic retry loop runs in the background.

Turning MCP off cancels a pending Tunnel start. Turning it on again permits a fresh one-shot start. Unloading the plugin cancels any pending timer. Explicitly stopping the Tunnel remains a saved preference.

All other DSH Dots 2.0.0 features are preserved, including web navigation, clickable Dot home, the Settings layout, the expandable connection guide, login retention, 17 MCP tools, selected-session notifications, and existing Tunnel client preferences.

## Install

Enter this in DSH **Plugins → Add plugin**:

```text
github:Tests4gptplay/dsh-dots#v2.0.1
```
