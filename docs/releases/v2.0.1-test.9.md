# DSH Dots 2.0.1-test.9：导航与隧道自动恢复

[返回项目介绍](../../README.md) · [上一候选版](v2.0.1-test.8.md) · [完整配置指南](../../README.md#连接自己的-dot)

## 导航更新

在 Dots 原生网页顶部新增“后退”按钮，使用 Electron WebView 的浏览历史。点击顶部 Dots 图标或文字整体回到 ChatGPT Dot 首页，沿用当前的 WebView 与浏览器登录分区。

## 设置页与配置引导

继续采用 2.0.1-test.8 的卡片布局、字号、边框、明暗主题和中英文样式。原有五步 MCP/Tunnel 接入指南及官方链接移到 MCP、OpenAI Secure MCP Tunnel 和主动通知三个区域下方，通过独立的折叠卡片展开。

GitHub 访客也可从 [README 的配置指南](../../README.md#连接自己的-dot) 直接查看注册、配置与首次调用步骤。

## 隧道启动状态

启动／停止选择保存在当前 DSH 用户配置中。上次开启的隧道在 DSH 本地 MCP 连接就绪后自动恢复；手动停止后下次启动仍保持停止。Runtime API Key 保存在当前 DSH 用户配置目录的独立权限受限文件，供自动恢复使用。

## 候选分支安装

在 DSH「插件 → 添加插件」中填写：

```text
github:Tests4gptplay/dsh-dots#2.0.1-test.9
```
