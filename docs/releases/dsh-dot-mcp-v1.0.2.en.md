# DSH Dot MCP 1.0.2

Fixes failures returning some larger screenshots through MCP by avoiding duplicate image transfers.

## Changes

- More reliable screenshot and image tool results.
- Images are not compressed; attachment metadata and native tool results are preserved.
- Keeps the `dsh-dot-mcp` installation identity and existing connection, tunnel and notification settings.

## Install or update

Use DSH plugin management to install or update `dsh-dot-mcp@1.0.2`, or install the release archive `dsh-dot-mcp-1.0.2.tgz`.

The classic Dots edition is unchanged.
