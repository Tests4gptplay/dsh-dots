# DSH Dot MCP 1.0.3

修复 Dots 登录保持在 DSH Desktop 退出和更新后的应用流程。若退出后的应用进程没有完成，设置会恢复为可重新操作；旧版卡住的「已安排」记录也可直接重新应用。沿用 `dsh-dot-mcp` 的安装身份和现有设置。

在 DSH 插件管理中更新 `dsh-dot-mcp@1.0.3`，也可安装本页的 `dsh-dot-mcp-1.0.3.tgz`。

## English

Fixes login-persistence recovery after a DSH Desktop exit or update. Interrupted deferred operations can be applied again, including stuck pending requests created by older releases. The package identity and existing settings are preserved.
