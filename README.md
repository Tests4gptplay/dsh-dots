# DSH Dots

在 DeepSeek Harness 内直接使用 [ChatGPT Dots](https://chatgpt.com/dots/home)。桌面版启动时预加载，切换 DSH 面板时保留网页与页面状态，并支持刷新或在系统浏览器中打开。

界面工具栏与圆环图标随 DSH 明暗主题变化，支持中英文显示；ChatGPT 账号直接在官方网页中登录。

**登录保持（Desktop）**：在 **DSH 设置 → Dots 登录保持** 中，可以查看状态、一键应用或恢复 Dots 专属浏览器的登录保持功能。

## 安装 DSH Dots 1.0.12（简洁版）

在 DSH「插件 → 添加插件」的「包名或地址」中输入以下固定分支地址：

```text
github:Tests4gptplay/dsh-dots#1.0.12
```

也可以使用已发布的 1.0.12 固定版本标签：

```text
github:Tests4gptplay/dsh-dots#v1.0.12
```

[下载 1.0.12 发行安装包](https://github.com/Tests4gptplay/dsh-dots/releases/download/v1.0.12/dsh-dots-1.0.12.tgz) · [1.0.12 更新与安装说明](docs/releases/v1.0.12.md)

**npm 已发布包名**：`@tests4gptplay/dsh-dots@1.0.12`。

安装后在侧栏打开 **DSH Dots**，使用 ChatGPT 官方网页登录；桌面登录保持功能在 DSH 设置中管理。
